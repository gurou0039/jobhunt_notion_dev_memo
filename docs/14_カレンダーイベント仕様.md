# 14 カレンダーイベント仕様

## イベント種別

MVPでは次の4種類を扱う。

| 表示 | `event_type` | 用途 |
| --- | --- | --- |
| 説明会 | `briefing` | 会社説明会、セミナー |
| 面接 | `interview` | 面接、面談 |
| 締切 | `deadline` | ES、Webテスト、応募などの締切 |
| その他 | `other` | 上記以外の就活予定 |

既存データの `seminar` は後方互換として表示時に「説明会」と扱うが、新規保存では `briefing` を使用する。

## 保存項目

- 必須: `workspace_id`、`title`、`event_type`、`start_at`
- 任意: `end_at`、`related_company_id`
- 入力日時は `Asia/Tokyo` として受け取り、SupabaseにはUTCの `timestamptz` として保存する。
- 終了日時は開始日時以降に限定する。
- 企業を指定した場合は、ログイン利用者が所有する企業だけを保存できる。

## 所有権とエラー処理

- イベントの参照・作成・更新・削除は #19 で追加したworkspace単位のRLSを利用する。
- 編集画面はRLSで参照できないイベントを404として扱う。
- 必須項目、日時の前後関係、企業の所有権、保存失敗をフォーム上のエラーとして表示する。

## 確認手順

1. ログイン後、カレンダーの「予定を追加」からイベントを保存する。
2. 月表示と週表示でイベントを選び、詳細の日時と種別を確認する。
3. 「予定を編集」から内容を変更し、カレンダーへ戻った後も変更が表示されることを確認する。
4. 再読み込み後も変更が残ることを確認する。
5. 編集画面から削除し、カレンダーとダッシュボードから消えることを確認する。
